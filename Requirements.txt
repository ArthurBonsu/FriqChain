We are building a African platform for tokenization the that aims to take all the African currency, provides a tokenized version of them and back them with a fair financial calculation for the value of each currency and tokens while taking into consideration the international financial system. However it should be able to be also convertible to global currencies such as the RMP, rupees, rubles, USD and Euros. This platform should not be held hostage by international financial system but the aim is to be independent of itself, we will use a public blockchain. They will connect with local bank and help facilitate transaction in respective countries. The aim is to be independent while still serving platforms.
